# 🌍 Solavise Tech — Women in Data Program | Cohort 2

## 📌 About the Program

The **Solavise Tech Women in Data Community Program** is a 2-month intensive learning experience designed to equip women with the technical skills, community, and confidence to build impactful careers in data and technology.

**Program Duration:** May 2, 2026 – June 28, 2026
**Schedule:** Saturdays & Sundays | 22:00HRS – 00:00HRS (EAT)
**Mode:** Fully Online (Live Sessions)

### What the Program Covers
- 🐍 Python for Data Analysis
- 🐼 Hands-on experience with pandas, NumPy, and data visualization tools
- 🗂️ Version control with GitHub
- 💼 Tech portfolio building and professional presence
- 🤝 Collaborative hackathon experience
