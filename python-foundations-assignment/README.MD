## ▶️ How to Run

Make sure Python 3 is installed, then run any file:

```bash

python control_flow.py
python data_structures.py
```

## 💡 What I Learned

Working through these exercises reinforced how Python's core building blocks — variables, operators, control flow, and data structures — work together to solve real problems. A few highlights:

- **Sets** are incredibly powerful for deduplication and finding relationships between groups of data — directly useful for data cleaning work
- **Dictionaries** mirror how real-world databases and APIs return data, making them essential for any data analyst
- **Control flow** is the foundation of any decision-making system — from ATM validations to login systems to health data quality checks
- Every exercise connects to something I'll use in real data work: cleaning, transforming, querying, and presenting information
